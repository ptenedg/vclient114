# vclient — сетевой клиент для обработки числовых векторов

Курсовая работа по дисциплине «Технологии и методы программирования».
Автор: Крылов Н.С., группа 25ПИ1.

Консольная программа на C++17 для Linux. Она читает числовые векторы из двоичного файла, передаёт их на сервер по протоколу TCP, получает результаты вычислений и сохраняет их в двоичный файл.

## Возможности

- чтение векторов из двоичного файла исходных данных;
- сеанс обмена с сервером: соединение, аутентификация, передача векторов, приём результатов, завершение;
- аутентификация по схеме `MD5(SALT16 || PASSWORD)` (собственная реализация MD5, без внешних библиотек);
- сохранение результатов в двоичный файл;
- диагностика ошибок: функция, значения параметров, тип ошибки.

## Требования

- Linux;
- компилятор `g++` с поддержкой C++17;
- `make`.

## Сборка

```bash
make
```

Очистка: `make clean`.

## Использование

```bash
./vclient -a АДРЕС -i ВХОДНОЙ_ФАЙЛ -o ВЫХОДНОЙ_ФАЙЛ [-p ПОРТ] [-c КОНФИГ]
```

| Параметр | Описание | Обязательный | По умолчанию |
|---|---|---|---|
| `-a` | сетевой адрес сервера | да | — |
| `-p` | порт сервера | нет | `33333` |
| `-i` | файл с исходными данными | да | — |
| `-o` | файл для результатов | да | — |
| `-c` | файл с LOGIN и PASSWORD | нет | `~/.config/vclient.conf` |
| `-h` | справка | нет | — |

Запуск без параметров также выводит справку.

Пример:

```bash
./vclient -a 127.0.0.1 -p 33333 -i input.bin -o result.bin
```

### Файл конфигурации

Первая строка — LOGIN, вторая — PASSWORD:

```
user
pass
```

Также допускается одна строка вида `LOGIN:PASSWORD` или `LOGIN PASSWORD`.

## Форматы файлов

**Исходные данные** (двоичный):

1. `uint32_t` N — число векторов;
2. N раз: `uint32_t` S — размер вектора, затем S значений `double`.

**Результаты** (двоичный):

1. `uint32_t` — количество результатов;
2. результаты по 8 байт (`double`).

## Протокол обмена с сервером

1. Клиент устанавливает TCP-соединение.
2. Клиент передаёт `LOGIN`.
3. Сервер передаёт `SALT16` (16 hex-цифр, дополнение слева нулями) или `ERR`.
4. Клиент передаёт `HASHMD5(SALT16 || PASSWORD)` (32 hex-цифры, верхний регистр).
5. Сервер отвечает `OK` или `ERR`.
6. Далее обмен в двоичном виде: клиент передаёт число векторов.
7. Для каждого вектора клиент передаёт размер, затем все значения одним блоком, сервер возвращает результат.
8. Клиент закрывает соединение.

## Структура проекта

```
vclient/
├── Makefile
├── README.md
├── src/
│   ├── main.cpp
│   ├── ClientApp.*       — разбор параметров, основной сценарий
│   ├── ConfigReader.*    — чтение LOGIN и PASSWORD
│   ├── FileManager.*     — чтение и запись двоичных файлов
│   ├── TcpClient.*       — работа с TCP-сокетом
│   ├── Authenticator.*   — аутентификация
│   ├── DataExchanger.*   — двоичный обмен векторами

│   ├── Credentials.h, VectorData.h, errors.h
│   └── md5.*             — реализация MD5
```

## Коды завершения

- `0` — успешно;
- `1` — ошибка (сообщение выводится в `stderr`).
